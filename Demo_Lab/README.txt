  IN/PV 03/Fused_St_Filt_Comp.jpg   = official test image Image_011 (experiment (2), G2, IN, PV 03; 5 µm)

These are Comp-stage mosaics (Fused_St_Filt_Comp) of the 5 µm experiments, included with the lab's agreement as
test data. The full check (run_full_check.command / run_full_check.bat) segments this folder and compares the
results with the reference maps in selftest/full_check/. Because the folder name says D07, the app fills hollow
particles with the 7 µm method here. The scan lists this README.txt as skipped ("file at top level").
